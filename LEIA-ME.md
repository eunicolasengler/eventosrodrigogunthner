# Site Rodrigo Gunthner
- Instalar: `npm install` · Rodar: `npm run dev` · Publicar: `npm run build` (pasta `dist/`).
- Tudo editável em `src/config/site.ts` (WhatsApp, redes, mídias, textos, IDs de rastreamento, endpoint do formulário).
- Pendências marcadas com CONFIRMAR no config: número (8 dígitos), domínio (SEO), categoria dos projetos, diferenciais, logotipo oficial.
- `dist/` já contém uma versão pronta (gerada com `tools/offline-build.mjs`).
